# Sam Nolan

Computer Science student at the University of Guelph. I build web apps, developer tools, and more.

I work on everything from frontend development to backend systems and infrastructure. Most of my projects start with an idea or something I want to build for myself.

I also run [byNolo](https://github.com/byNolo), where I'm building independent software projects.

### A few projects

- **[Nookfield](https://github.com/byNolo/Nookfield)** Real time coordination and location sharing for in-person events, with privacy controls.
- **[Vinyl Vote](https://github.com/SamN20/Vinyl-Vote)** An album of the week voting app with notifications and community features.
- **[Reel Review](https://github.com/SamN20/Reel-Review)** A community movie rating app built around weekly picks and discussions.
- **[Mina](https://github.com/SamN20/Mina)** An AI-powered Discord voice bot with conversation memory, speech recognition, soundboard, join/leave sounds, and more.
- **[Draftory](https://github.com/byNolo/Draftory)** A sports drafting and season simulation project powered by Rust and WebAssembly.
